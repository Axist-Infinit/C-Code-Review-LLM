# Optional: the LangChain backend (providers.LangChainBackend), which lets the
# reviewer run against an EXISTING hosted or self-hosted model instead of a
# locally pulled Ollama tag.
#
#   pip install -r requirements-langchain.txt
#   pip install langchain-anthropic          # then, per provider you actually use
#
# NOT needed for the default offline pipeline. The Ollama backend is stdlib-only
# on purpose so build_airgap_bundle.sh / offline_lockdown.sh keep working on a
# box with nothing installed, and providers.py never imports langchain at module
# scope — only when a spec names a LangChain provider.
#
# Deliberately lower-bounded rather than pinned like requirements.txt: this is an
# optional lane whose provider packages release on their own cadence, and the
# only API surface used is init_chat_model + .invoke(), stable across 1.x.
# Verified against langchain 1.3.15 / langchain-core 1.5.5.
langchain>=1.0
langchain-core>=1.0
